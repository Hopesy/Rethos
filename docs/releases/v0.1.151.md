# Rethos 0.1.151

网页登录统一使用可重复使用的访问 Token。换浏览器时输入同一个 Token，各浏览器独立保持登录。

- 重做登录页：Rethos 品牌山景、紧凑表单、浅色与深色主题，以及手机单栏布局。
- 登录表单保留 Token 输入和登录按钮，移除临时配对入口、获取 Token 帮助和输入框上方的重复提示。
- 设置 → 通用新增访问 Token 管理，支持创建、复制及撤销；网页创建的 Token 有效期为 90 天。
- 已登录网页可生成手机登录二维码，手机扫码确认服务器后登录；二维码 5 分钟有效、单次使用，关闭或刷新时取消旧二维码。
- 撤销 Token 同时结束关联浏览器与扫码登录的手机会话。
- 首次部署通过服务器 `rethos token create` 创建 Token，安装和恢复步骤已同步到 README 与 VPS 文档。

发布产物包含 Windows x64 安装程序、便携 ZIP、桌面更新文件，以及 AMD64 / ARM64 VPS 镜像。现有数据卷与浏览器会话沿用。

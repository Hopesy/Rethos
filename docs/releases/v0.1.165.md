# Rethos 0.1.165

修复自托管服务器上的定时任务访问连接电脑、项目 Bot 委派授权，以及 Token 网页登录后的设备归属。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.165/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.165/Rethos-Android.apk) |

- 同一访问 Token 及其网页登录会话使用相同的电脑访问身份，网页工作位置选择可显示该 Token 已连接的电脑。
- 个人自托管服务器记录监控的授权人和任务配置，定时运行时核对有效身份、当前执行轮次和配置，再访问已授权电脑。
- 主 Bot 委派给项目 Bot 的任务沿现有协调链使用电脑授权。暂停监控、停止任务、修改指令或撤销 Token 后，相应授权失效。
- 等待授权或等待桌面空闲的操作在继续执行前重新核对身份。
- 保留现有调度器、定时周期及本机原生连接组件；其他用户、Webhook 和无有效来源的请求继续隔离。

升级后，已有监控由本人打开编辑器并保存一次完整指令，以登记授权来源；在 Bot 的工作位置中选择实际连接的电脑。项目 Bot 沿用各自的权限设置。

Windows 与 Android 共用版本 0.1.165。Android versionCode 为 1165，沿用原签名和应用 ID。

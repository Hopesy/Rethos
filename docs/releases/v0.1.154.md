# Rethos 0.1.154

登录按钮统一使用黑色，新建机器人的问候与引导完整支持简体中文。

- 登录按钮在浅色、深色主题和空 Token 状态下均保持黑色背景；填写 Token 后可登录，空值时保持禁用。
- 新建机器人的首条问候、五个引导选项和配置提示支持简体中文，包括 `zh-CN`、`zh-Hans` 和 `zh-SG`。
- 未指定应用语言时，服务端使用浏览器报告的语言生成问候与配置引导。
- 机器人的默认名称与命名规则保持原样。
- 包含 0.1.153 的登录页优化：精简重复品牌图标，移除卡片阴影与高光，并收紧 Android 内嵌页面的页头留白。

现有 Android 0.1.0 客户端重新加载网页即可使用本次更新。

已通过针对本次改动的登录、问候、语言选择与配置请求测试；隔离服务器验证了“明确设置中文”和“浏览器中文、应用语言留空”两种创建流程，生成的默认名称保持原样。

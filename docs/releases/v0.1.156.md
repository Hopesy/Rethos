# Rethos 0.1.156

Windows 与 Android 从本版本起使用统一版本号，并在同一个 Release 发布。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.156/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.156/Rethos-Android.apk) |

- 手机端 Agent 回复使用完整消息区域，长段落、列表和代码阅读更宽敞；消息操作显示在回复下方。
- 手机输入内容后，语音通话入口切换为 44px 的发送按钮，避免语音和发送按钮紧贴；保留添加菜单中的通话入口。
- Android 沿用原应用 ID 和签名，版本 0.1.156 / versionCode 1156，支持覆盖升级并保留登录。
- Windows 安装程序沿用现有未签名构建方式。

Assets 中两个安装包供直接下载；`latest.yml` 与 `.blockmap` 用于 Windows 自动更新，`SHA256SUMS.txt` 用于校验。详细构建记录和 Windows 便携 ZIP 保存在同次 Actions 构建产物中。

[网页入口](https://rethos.hopesy.cc) · [安装与更新说明](https://github.com/Hopesy/Rethos/blob/v0.1.156/docs/releasing.md)

# Rethos 0.1.155 · Windows

更新手机登录入口和 Rethos 设置兼容性，并同步 Android 0.1.2 下载入口。

- 网页手机入口连接 Android 原生扫码流程；手机应用下载按钮与二维码指向 Android 0.1.2。
- 发布页、帮助文档和源码入口统一指向 `Hopesy/Rethos`。
- 修复旧设置分组入口和部分语言下的设备日期显示；保留已有配对凭据与内部协议兼容性。
- 修复全量 CI 的品牌与打包校验、跨平台测试夹具和异步时序问题，补充失败摘要与诊断文件。

仓库同时提供 `deploy/desktop/Install.cmd`，在 Windows 上填写 VPS 信息后配置独立 CUA、反向 SSH、后台登录任务与 VPS MCP。维护入口包括检查、更新和卸载，详情见 [桌面一键安装](../../deploy/desktop/README.md)。

[下载 Windows 0.1.155 安装程序](https://github.com/Hopesy/Rethos/releases/download/v0.1.155/Rethos-setup.exe) · [下载 Android 0.1.2](https://github.com/Hopesy/Rethos/releases/download/android-v0.1.2/Rethos-Android-0.1.2.apk)

Windows x64 提供 NSIS 安装程序、便携 ZIP 和自动更新元数据。工作流实际安装并启动桌面，验证内置浏览器、服务端、模块范围及发布文件摘要。Windows 安装包沿用当前未签名配置；构建来源和 SHA256 随 Release 提供。

# Rethos 0.1.162

统一电脑接入与工作位置，清理商业托管入口和后台依赖。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.162/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.162/Rethos-Android.apk) |

- Bot 默认工作位置与当前会话可选择具体的已连接电脑，并保存该电脑上的工作目录。修改授权、重连和刷新后沿用电脑身份，目标离线时提供明确反馈。
- 简易和高级模式共用工作位置设置；会话可固定目标、关闭电脑访问或恢复跟随 Bot。连接电脑与自有 VPS、本地虚拟机分别展示。
- 网页设置可暂停、恢复或撤销当前服务器对电脑的接入。权限按电脑授权、Bot 工具范围、会话访问模式及任务状态共同执行；撤销和停止后停止后续操作。
- 删除商业托管账号、购买、套餐、试用、Boat 桌面及相关后台请求、凭据和 IPC；移除依赖旧托管服务的页面发布工具，保留对话内网页、图表和用户自配模型/API。
- 迁移旧桌面配置。使用已移除服务的例行任务保持停用并提示检查工作位置；现有自有 VPS、模型、记忆和用户权限继续保留。
- 修复电脑面板读取已删除配置造成空白的问题，统一目标选择器；暂停和关闭时显示准确状态，详细说明放入帮助浮层。
- 修复桌面首次启动的配置缺失、初始化顺序和旧权限回调问题，完成隔离安装启动验收。

Android 版本为 0.1.162 / versionCode 1162，沿用原签名与应用 ID。Windows 沿用现有安装与自动更新方式。

# Rethos 0.1.157

高级设置改用简短说明，标题旁的帮助图标提供完整解释，支持鼠标悬停、键盘聚焦和手机点击。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.157/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.157/Rethos-Android.apk) |

- 精简通用、外观、实验功能，以及 Bot 的访问、权限、模型、记忆、身份和技能设置说明；补齐按键说话、已保存步骤和浏览器录制等条件设置。
- 帮助浮层保持单个显示，键盘与鼠标交替操作时也能正确切换；按 Esc 关闭帮助后继续留在设置页，窄屏下保持浮层在屏幕内。
- 浏览器帮助内容随启用、停用和可用状态更新，缺少浏览器配置时可直接打开对应设置。
- 费用、截图保存期限、个人信息共享与配置异常继续显示在设置旁；完整规则保留在帮助内容中。
- 同步英文、简体中文和繁体中文文案。

Android 版本为 0.1.157 / versionCode 1157，沿用原签名和应用 ID，支持覆盖升级并保留登录。Windows 沿用现有未签名安装包方式。

Assets 中的两个安装包供直接下载；`latest.yml` 与 `.blockmap` 用于 Windows 自动更新，`SHA256SUMS.txt` 用于校验。详细构建记录和 Windows 便携 ZIP 保存在同次 Actions 构建产物中。

# Rethos 0.1.160

提高主 Bot 和 API 模型长任务的执行额度，并精简工具搜索的聊天提示。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.160/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.160/Rethos-Android.apk) |

- 每轮模型执行步骤从 64 提高至 1,024，累计工具调用从 200 提高至 10,000，适用于使用 Rethos 共享 API 运行时的 Bot。
- 运行时与引擎能力说明共用同一份额度配置。主动停止、重复调用 ID 检查、错误处理和额度耗尽后的交接记录继续生效。
- 超出剩余额度的整批调用在执行前停止，交接记录准确统计已接纳的调用。
- 正常使用 MCP 工具搜索时，聊天保持安静；工具状态继续显示在 Bot 设置页，连接失败和实际工具裁减继续提供提示。

Android 版本为 0.1.160 / versionCode 1160，沿用原签名与应用 ID。Windows 沿用现有安装与自动更新方式。

公开文件包含两个安装包、Windows 更新索引和差分文件、SHA256 校验表。

[网页入口](https://rethos.hopesy.cc) · [安装与更新说明](https://github.com/Hopesy/Rethos/blob/v0.1.160/docs/releasing.md)

# Rethos 0.1.166

修复选择已连接电脑后电脑面板标签消失、设备重复展示，以及简易模式的任务计划入口。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.166/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.166/Rethos-Android.apk) |

- 选择已连接电脑后继续显示完整电脑面板。简易模式保留屏幕、浏览器、数据、文件标签，高级模式保留屏幕、例行任务、浏览器、数据标签；连接手机时继续提供手机入口。
- 浏览器开关和安装设置、关闭面板、调整宽度与键盘切换标签沿用原有功能。
- 工作位置、访问设置和屏幕面板统一通过原位置的设备卡片展示电脑，移除重复的“已连接电脑”列表。全局电脑设置继续提供暂停、继续和停止分享。
- 简易模式下“打开计划”进入当前 Bot 的任务计划页。
- 连接电脑的选择和会话工作目录继续保存；访问该电脑时跳过其他桌面的自动发现、启动和预览请求。

Windows 与 Android 共用版本 0.1.166。Android versionCode 为 1166，沿用原签名和应用 ID。VPS 通过 Docker Compose 更新服务端镜像。

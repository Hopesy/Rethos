# Rethos 0.1.161

统一已连接电脑的文件、终端与桌面入口，让本机和 VPS 上的 Bot 使用同一套会话权限规则。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.161/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.161/Rethos-Android.apk) |

- 连接自己的服务器时，电脑访问设置新增“跟随 Bot 权限”。普通模式直接访问已授权目录，访问其他目录或申请写入时显示授权卡片；完全访问模式可读写当前系统账号可访问的目录。
- 目录授权按 Bot 和本次任务隔离。停止任务、降低权限或撤销电脑访问后，后续操作重新检查授权；后台连接器重启保留已撤销的访问状态。
- 文件读取支持大日志分段、末尾读取和按偏移继续读取，保留 UTF-8 字符边界；目录列表支持分页和按修改时间排序。
- 同一访问令牌登录的浏览器与本机连接器具有一致的电脑所有者身份，修复两端登录后电脑可见性不一致的问题。
- 提供复用原生电脑通道的独立后台连接器，将文件、终端和 CUA 桌面操作集中到同一台已连接电脑。
- 目录权限设置使用简短说明，鼠标悬停可查看详细规则。

Android 版本为 0.1.161 / versionCode 1161，沿用原签名与应用 ID。Windows 沿用现有安装与自动更新方式。

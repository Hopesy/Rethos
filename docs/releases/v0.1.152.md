# Rethos 0.1.152

自定义模型统一在 AI 设置中管理，支持 OpenAI Chat、OpenAI Responses 与 Anthropic Messages 协议。配置模型地址、密钥和模型后，可点击拉取模型左侧的测试图标，保存前验证连接并查看耗时。

- Anthropic Messages 支持流式回复、图片与工具调用，沿用现有工具权限和审批流程。
- 模型列表按所选协议读取；服务未提供模型列表时可手动输入模型 ID。
- AI 设置移除重复的自定义端点添加入口，已有 Claude Code 连接仍可在自定义模型区域管理。
- 修正关闭 VPS 电脑功能时的提示词：机器人会按实际挂载的自定义 MCP 查看本机桌面，并在报告任务进度前获取当前观察结果。
- 获取手机应用仅显示 Android 下载，二维码和按钮指向本仓库发布的 APK，安装后使用 Token 登录。

发布产物包含 Windows x64 安装程序、便携 ZIP、桌面更新文件，以及 AMD64 / ARM64 VPS 镜像。VPS 升级沿用现有数据卷、模型配置、Token 与桌面 MCP。Android 客户端继续使用 0.1.0，联网访问升级后的 Web 页面即可使用本次网页更新。

# Rethos 0.1.159

补齐默认主 Bot 的工具开放规则，修复复制 Bot、保存工具设置和编辑记忆时的七项问题。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.159/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.159/Rethos-Android.apk) |

- 默认主 Bot 在简易和高级模式下始终开放工作区中可用的 MCP、应用工具、浏览器、手机工具、研究、语音工具和记忆。启动时自动修复旧配置遗留的限制。
- 复制普通 Bot 时，从首次创建起保留源 Bot 的工具范围、记忆开关、MCP 和应用授权，避免新建默认配置改变副本的能力。
- 工具设置保存期间，消息等待保存成功后执行。保存失败时保留草稿和具体错误，支持修正或重试。
- 工具保存的迟到响应只更新工具选择，保留期间已经更新的记忆等状态。
- 点击“保存默认配置”或创建 Bot 时，统一提交并校验工具草稿。
- 记忆草稿、保存状态和错误在模式切换、关闭并重新打开设置后继续保留；冲突副本也可继续查看。
- 记忆保存期间继续输入的内容保持为待保存状态，旧响应不会覆盖新输入。

Android 版本为 0.1.159 / versionCode 1159，沿用原签名和应用 ID，支持覆盖升级并保留登录。Windows 沿用现有未签名安装包方式。

Assets 中的两个安装包供直接下载；`latest.yml` 与 `.blockmap` 用于 Windows 自动更新，`SHA256SUMS.txt` 用于校验。详细构建记录和 Windows 便携 ZIP 保存在同次 Actions 构建产物中。

# Rethos 0.1.164

修复工作位置选择的名称与连接状态刷新，保留原有卡片网格。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.164/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.164/Rethos-Android.apk) |

- 已连接电脑直接显示在原有工作位置卡片中，显示设备名与在线、离线或暂停状态。简易模式保留三列卡片，高级模式保留两列卡片。
- 将“依照机器人…”缩短为“跟随 Bot”，名称支持换行。会话跟随的默认位置已为自动时，简易模式收起重复的自动选项；已有明确固定的自动选择继续保留。
- 将运行 Bot 的主机桌面标为“Bot 所在电脑”，避免在 VPS 页面中根据客户端平台显示成“这台 PC”。连接用户电脑时选择对应设备名。
- 工作位置面板在电脑上线、暂停或恢复后自动更新，返回页面时刷新，也可点击标题旁的刷新按钮。页面隐藏或面板关闭后减少后台请求。
- 设备状态刷新保留所选电脑和工作目录，保存期间忽略较早请求返回的旧状态。

Windows 与 Android 共用版本 0.1.164。Android versionCode 为 1164，沿用原签名和应用 ID。

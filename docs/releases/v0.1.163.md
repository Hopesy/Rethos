# Rethos 0.1.163

加强主 Bot 与项目 Bot 的协作，支持持续推进长目标，合入通用上游更新并保持自部署版本。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.163/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.163/Rethos-Android.apk) |

- 主 Bot 可创建项目 Bot、带文件分派任务、接收结果与文件，并更新项目及汇总记忆。默认主 Bot 在简易和高级模式下保持工具与记忆开放。
- 单 Bot 与团队目标取消固定 13 轮上限，持续推进直到完成、主动停止或触发预算等现有约束；保留忙碌等待、重复分派检查和取消处理。
- 恢复连接电脑的卡片界面。模式切换和重复选择当前电脑保留工作目录；暂停、撤销与离线状态准确显示。
- 修复暂停 Bot 后仍接收任务、部门重命名丢失暂停状态，以及桌面接管期间切换工作位置的保护检查。设置弹层保持焦点，手机设置链接可正确打开。
- 补齐简体中文文案；诊断、并发和私有桌面设置使用简短说明与悬浮帮助，自定义模型连接统一管理。
- 保留自托管服务器之间的 Bot 分派、双向文件传递和结果续接。当前通过配对 API 配置，专用凭据限定于协作链路。
- 修复“始终允许”的保存校验，定时任务支持复用同一会话，会话标题支持批量重新生成；已取消的监控继续保持原状态。
- 增加兼容 OpenAI API 的自定义 Live 端点、每个 Bot 的通话声音、Fish Audio 语言选择，改进决策模型协议与 OpenRouter 缓存。
- 合入 Antigravity 配额显示与客户端兼容、OpenCode 免费模型额度恢复、macOS 系统代理、桌面粘贴、Gmail 分页、浏览器诊断和长聊天凭据卡显示等改进。
- 官方商业云账号、购买、套餐、试用及关联自动配对界面继续删除；清理残留赞助卡片与推广统计，保留用户自己的模型、API、电脑和 VPS。

Android 版本为 0.1.163 / versionCode 1163，沿用原签名与应用 ID。Windows 沿用现有安装与自动更新方式。

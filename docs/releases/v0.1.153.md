# Rethos 0.1.153

登录页精简品牌展示，并使用贴合页面的细边框卡片。

- 移除登录卡片内重复的应用图标和图标外框。
- 桌面版沿用左侧场景中的品牌；普通手机浏览器在页头显示一处品牌。
- Android WebView 登录页面沿用原生应用栏的品牌展示，并收紧页头留白。
- 移除登录卡片的浮动阴影、顶部高光及表单区域的背景光晕，沿用现有设计颜色与圆角。

Token 登录、手机扫码及主题切换保持原有流程。现有 Android 0.1.0 客户端刷新网页后即可加载新样式。

已验证 390px 手机布局、Android WebView 标识下的页面布局、桌面布局、浅色和深色主题；12 项登录与扫码组件测试通过。

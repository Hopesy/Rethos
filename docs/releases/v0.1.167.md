# Rethos 0.1.167

修复共享电脑以相同权限重新登记时，正在使用它的定时任务或 Bot 对话偶发报错 `The requesting turn ended` 的问题。

| 平台 | 下载 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.167/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.167/Rethos-Android.apk) |

- 同一设备刷新登记时，待审批、领取和执行中的请求可以继续。
- 暂停、撤权、变更授权范围或切换设备归属后，旧请求和旧目录审批会失效；恢复共享后按当前权限处理新请求。
- 错误信息区分了连接变化、设备授权变化和请求结束，便于定位失败步骤。

此修复在服务端生效。Windows 与 Android 共用版本 0.1.167，Android versionCode 为 1167。

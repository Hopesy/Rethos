# Rethos 0.1.150

- 使用新的 Rethos 小猫图标，统一网页、PWA、桌面窗口、托盘与 Windows 安装包资源。
- 配对页改为单个授权码输入框；设备名称自动识别，获取授权码的说明可展开，终端命令支持一键复制。支持手机窄屏和浅色、深色主题。
- 简化为自建服务器与本地工作空间的入口，移除官方云购买、云账号和组织/团队空间的设置、菜单及引导。桌面端停止恢复官方云和组织账号。机器人之间的团队协作继续保留。
- AI 设置优先显示自定义 API 连接，支持 Chat Completions / Responses 协议、读取服务端模型列表、手动添加模型和设置默认模型。
- 优化模型选择、协议菜单、图标按钮和设置页间距，补充简体中文文案，将较长的设置说明收进帮助。

## 下载与更新

- Windows 安装包：`Rethos-0.1.150-setup.exe`；固定下载名：`Rethos-setup.exe`。
- Windows 便携包：`Rethos-0.1.150-x64.zip`。
- Docker：`ghcr.io/hopesy/rethos:v0.1.150`，支持 AMD64 和 ARM64。
- Windows 安装包、更新元数据和校验文件由发布工作流生成。现有数据目录继续沿用。

## 维护

图标源文件为 `build/icon.svg`，运行 `node scripts/build-brand-icons.mjs` 可重新生成网页和桌面图标。修改后应一起提交生成的资源。

配对继续使用一次性授权码与设备会话。授权码默认有效期 10 分钟；正常会话由服务端续期，刷新页面继续使用已有连接。

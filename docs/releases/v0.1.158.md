# Rethos 0.1.158

修复切换简易、高级模式时工具设置草稿与保存错误丢失的问题，并为工作区默认主 Bot 保持完整工具和记忆能力。

| 平台 | 下载安装 |
| --- | --- |
| Windows x64 | [Rethos-setup.exe](https://github.com/Hopesy/Rethos/releases/download/v0.1.158/Rethos-setup.exe) |
| Android 8.0+ | [Rethos-Android.apk](https://github.com/Hopesy/Rethos/releases/download/v0.1.158/Rethos-Android.apk) |

- 默认主 Bot 在简易与高级模式中始终使用全部可用工具，记忆始终开启。启动时自动修复它的旧工具白名单与关闭的记忆设置。
- 工具选择草稿按 Bot 保留。切换界面模式、关闭并重新打开设置后，可以继续修改、保存或放弃编辑。
- 保存过程中的状态和错误持续显示；保存失败时保留草稿，支持重试。成功后立即显示服务端确认的设置。
- 简易模式增加工具选择入口和记忆状态，复用高级模式的保存逻辑。普通 Bot 继续支持独立工具限制和记忆开关。
- 同步英文、简体中文和繁体中文提示。

Android 版本为 0.1.158 / versionCode 1158，沿用原签名和应用 ID，支持覆盖升级并保留登录。Windows 沿用现有未签名安装包方式。

Assets 中的两个安装包供直接下载；`latest.yml` 与 `.blockmap` 用于 Windows 自动更新，`SHA256SUMS.txt` 用于校验。详细构建记录和 Windows 便携 ZIP 保存在同次 Actions 构建产物中。

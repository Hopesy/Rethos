# 电脑接入、工作位置与商业服务移除

目标：完成原生电脑接入与 Bot/会话工作位置整合，删除商业运行入口，发布 Windows、Android 与 VPS 的统一版本 0.1.162。用户已授权修复、提交、push、发布和 VPS 备份升级。

## 产品与数据契约

- 全局“电脑接入”管理该电脑向当前服务器开放的能力、暂停和撤销；Bot“工作位置”管理默认执行目标，会话可以覆盖或恢复跟随。
- 已连接电脑与 Rethos 管理的私有 VPS/本地虚拟机分别展示。连接器使用出站 HTTPS 注册与长轮询；私有 VPS 使用现有 SSH/Docker 通道。
- `shared/work-target.ts` 是目标与迁移的权威来源；Bot 默认值、会话目标和远端 cwd 由 Store 与目标 API 持久化。Windows cwd 按 Windows 路径规则处理。
- 设备 ID 与连接凭据跨授权更新和重连保留，授权版本独立变化。不同电脑具有各自 ID；历史记录保留身份，按 ID 关联，避免按同名设备合并。
- 有效权限按电脑接入授权、能力、Bot 工具范围、会话模式、所有者与任务代次共同计算。普通模式保留目录和写入申请，Full 按当前系统账号范围执行。Off 覆盖文件、终端与桌面；撤销、Stop、目标和权限变更使旧操作失效。
- 服务器设置中的暂停作用于该服务器，托盘保留全部连接暂停。明确重新授权才恢复已撤销接入；自动能力刷新保留暂停与撤销。
- 桌面启动补齐共享颜色资源，修正初始化顺序、缺少启动记录时的默认工作区恢复，并删除权限处理器残留的商业账号回调。自有服务器的麦克风申请、剪贴板写入、通知和全屏继续按当前来源与主窗口判断。
- 自配模型/API、MCP、配对、自有服务器迁移、原生电脑、本地虚拟机、私有 VPS 和对话内网页继续保留。原托管账号、购买、套餐、试用、赠送凭据、Boat 执行器及商业页面发布入口已移除。
